# 🎯 任务规划 × 番茄工作法 × 每日报告

学习工具箱 (Learning Toolbox)**一个轻量级的个人任务管理系统**，集任务规划、番茄工作法计时、每日报告分析于一体。帮助你高效规划任务、专注完成工作、科学管理时间。

## ✨ 核心亮点

### 🗓️ **智能任务规划**
- 📅 规划当天及未来任务，一目了然
- ⚠️ **智能冲突检测**：自动识别时间重叠任务
- 🔍 **重复任务警告**：防止误创建相同任务
- 🎖️ 五级优先级设置，科学排序
- 🏷️ 详细描述和截止日期管理
- ⏰任务开始前提醒，防止遗忘

### ⏱️ **专注番茄工作法**
- ⏲️ 自定义工作/休息时间配置
- 🎯 一键启动专注计时，消除干扰
- 📊 自动记录番茄成果到每日报告
- 🔔 完成提醒，助力时间管理

### 📊 **每日报告与数据分析**
- 📈 **完成率统计**：一览每日任务完成进度
- 📉 **任务对比**：已完成 vs 未完成任务清单
- 📅 **历史查询**：回溯任意日期的任务数据
- 💡 **数据驱动决策**：优化每日任务规划

### 🎨 **优雅的用户体验**
- 🌓 深色/浅色主题随意切换
- 🎨 自定义背景支持
- 📱 响应式界面设计
- ⚡ 流畅的动画交互

## 🎯 功能详解

### 1️⃣ 任务规划模块 (`main.py`)

**MainWindow** - 任务管理中心
- 📝 创建新任务：名称、优先级、截止日期、描述
- ✏️ 编辑已有任务：实时更新任务信息
- 🗑️ 删除任务：一键移除完成或不需要的任务
- 🔍 搜索&排序：按优先级、日期灵活筛选

**TaskCard** - 任务卡片组件
- 优先级颜色标识（红↔绿渐进）
- 截止时间倒计时提醒
- 快速访问任务详情

**ReadWindow** - 任务详情窗口
- 📖 完整任务信息展示
- 🔐 防误操作确认机制

**智能验证**
- ⚠️ **时间冲突检测**：任务时间重叠时提示
- 🔄 **重复任务警告**：相同名称任务自动识别

### 2️⃣ 番茄工作法模块 (`pomodoro.py`)

**PomodoroWindow** - 专注计时窗口

```
工作时间 ⏱️  →  完成 ✅  →  自动记录 📊
```

**核心功能**：
- ⏲️ 自定义工作时间（默认25分钟）
- 🎯 选择任务后一键启动
- ⏸️ 暂停/继续控制
- 📊 完成任务自动同步到每日报告

### 3️⃣ 每日报告模块 (`daily_recorder.py`)

**DailyRecorder** - 数据管理引擎

**报告内容**：
```
📅 2025-11-17 报告
━━━━━━━━━━━━━━━━━
✅ 已完成 (3个)
  • 完成需求文档
  • 代码审查
  • 项目规划

❌ 未完成 (2个)
  • 单元测试
  • 性能优化

📊 完成率: 60%
⏱️ 番茄计数: 8个
```

**功能特点**：
- 📈 自动统计完成率
- 🔍 历史数据查询
- 📋 可视化报告展示
- 💾 持久化数据存储

## 💾 数据结构

### tasks.json - 任务库
```json
{
    "1700206800": {
        "name": "完成项目文档",
        "date": "2025-11-17",
        "level": 3,
        "create": "2025-11-17 10:30:00",
        "description": "整理API文档和使用说明",
        "time": 1700206800
    }
}
```

### daily_records.json - 每日报告库
```json
{
    "2025-11-17": {
        "completed": ["完成项目文档", "代码审查"],
        "uncompleted": ["单元测试"],
        "pomodoro_count": 8
    }
}
```

### config.json - 应用配置
```json
{
    "theme": "dark",
    "background": "default",
    "sort_by": "priority",
    "pomodoro_work_time": 25,
    "pomodoro_rest_time": 5
}
```

## ⚙️ 高级配置

### 自定义番茄时间

编辑 `config.json`：
```json
{
    "pomodoro_work_time": 50,
    "pomodoro_rest_time": 10
}
```

### 切换主题

**应用内**：设置 → 主题选择 → 立即应用

**手动配置**：编辑 `config.json`
```json
{
    "theme": "dark"  // 或 "light"
}
```

### 自定义颜色方案

编辑 `theme.json`：
```json
{
    "dark": {
        "bg": "#1e1e1e",
        "fg": "#ffffff",
        "accent": "#0078d4",
        "success": "#28a745",
        "warning": "#ffc107"
    }
}
```

## 🔐 数据安全

- 💾 **本地存储**：所有数据存储在本地JSON文件
- 🔒 **无云上传**：隐私完全掌控
- 📋 **定期备份**：建议备份 `tasks.json` 和 `daily_records.json`
- 🛡️ **数据恢复**：丢失时运行 `init_project.py` 重置

## 🐛 故障排除
